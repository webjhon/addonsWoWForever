# Lacunas atualmente abertas no conhecimento

Esta atualização contém resumos de material oficial e dados de estrutura. Ela **não** equivale ao banco completo do cliente Forever.

## Pendências críticas
- QuestIDs, flags de disponibilidade, cadeias, NPCs e coordenadas do conteúdo novo.
- IDs e ranks de talentos de classe e Legacy, incluindo pré-requisitos exatos.
- Catálogo atualizado de pet spawns, pet skills e treinador de Hunter Forever.
- MapIDs, dungeon journal IDs e geometria de instâncias novas.
- Localização de treinadores, flight masters e rotas segmentadas por facção.
- API export atualizada da build instalada, com confirmação de assinaturas de funções.
- Restrição de valores secretos e chamadas protegidas com testes no cliente.

## Ordem de preenchimento recomendada
API atual do cliente -> dados Legacy -> classe Hunter -> quest chains da Alliance -> transporte -> pets -> dungeon quests -> ferramentas de combate permitidas.

## Política
Somente importar dados de terceiros com licença compatível ou acesso autorizado. Zygor e RestedXP não devem virar conteúdo público copiado. Registre lacuna antes de inventar uma resposta.
