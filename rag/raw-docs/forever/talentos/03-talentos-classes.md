# Talentos de classe no Forever: NÃO confundir com Legacy

A Blizzard detalhou árvores de talentos de classe disponíveis a partir do nível 10. O desenho preserva marcos de um ponto em 11, 21 e 31 pontos investidos e introduz um novo marco de **16 pontos**. Talentos e habilidades existentes foram alterados e o jogo não deve ser modelado como uma cópia do Classic 1.12.

Para alterar a distribuição de talentos, incluindo talentos Legacy, o jogador deve procurar um instrutor de classe numa grande cidade, conforme os detalhes oficiais. **Dual Specialization** é anunciado a partir do nível 40.

## Para addons
- Distinguir nível de personagem, pontos investidos, requisito de desbloqueio e árvore.
- Não assumir que um ponto de talento corresponde ao nível da habilidade.
- Não usar guias de talentos do Classic como dados confirmados do Forever.
- Para cálculo de build de talentos: precisa importar talentIDs e regras verificadas na build atual.
- Se a API de talentos não puder ser comprovada, apresentar plano conceitual e bloquear a alegação de integração funcional.
