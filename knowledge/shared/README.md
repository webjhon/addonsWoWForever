# Conhecimento compartilhado

Use registros Neutral com flags independentes de acesso, fundamentadas em fontes. Compartilhar uma dungeon não comprova que todas as suas quests, entradas ou pré-requisitos atendem ambas as facções. Para elegibilidade bilateral de gameplay, declare alliance_access:true e horde_access:true com a procedência de cada campo. Não mover fatos Alliance para este diretório apenas para satisfazer cobertura. Consulte docs/FACTION-SUPPORT.md.
